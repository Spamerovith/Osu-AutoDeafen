# Osu AutoDeafen

**Osu AutoDeafen** automatically presses a configurable deafen/mute key when you reach a selected percentage in an osu! beatmap

It is inspired by the AutoDeafen concept for Geometry Dash and adapted specifically for osu!

## Features

- Set the percentage at which AutoDeafen activates
- Automatically presses your configured deafen/mute key
- Configurable hotkey
- Works automatically while playing osu!
- Simple setup - no installation required

## Installation

1. Go to the **Releases** section of this GitHub repository
2. Download the latest `OsuAutoDeafen-windows-x64` release
3. Open the downloaded `OsuAutoDeafen-windows-x64` folder
4. Run `OsuAutoDeafen.exe`
5. Configure the activation percentage and your deafen/mute hotkey
6. Start osu! and play normally

## How it works

For example, if you set the activation percentage to **70%**, Osu AutoDeafen monitors your current osu! play

When you reach 70% of the beatmap, it automatically presses the configured key

You can bind this key to Discord Deafen, allowing you to automatically deafen yourself before reaching a difficult part of a map

## Requirements

- Windows x64
- osu!
- A configured deafen/mute keybind if you want to use it with Discord

## Usage

1. Launch `OsuAutoDeafen.exe`
2. Select the percentage where AutoDeafen should activate
3. Set the key that should be pressed
4. Start playing osu!
5. Osu AutoDeafen handles the rest automatically

## Notes

Osu AutoDeafen runs separately from osu! and does not modify beatmaps or gameplay

It only triggers the configured key when the selected percentage is reached

# Osu AutoDeafen

**Osu AutoDeafen** автоматически нажимает заданную клавишу дефа/мута, когда ты достигаешь выбранного процента карты в osu!

Программа основана на идее AutoDeafen для Geometry Dash, но адаптирована специально для osu!

## Возможности

- Можно выбрать процент, на котором сработает AutoDeafen
- Автоматическое нажатие заданной клавиши дефа/мута
- Настраиваемый хоткей
- Автоматическая работа во время игры в osu!
- Установка не требуется

## Установка

1. Открой раздел **Releases** этого GitHub-репозитория
2. Скачай последнюю версию `OsuAutoDeafen-windows-x64`
3. Открой скачанную папку `OsuAutoDeafen-windows-x64`
4. Запусти `OsuAutoDeafen.exe`
5. Настрой процент срабатывания и клавишу дефа/мута
6. Запусти osu! и играй как обычно

## Как это работает

Например, если установить срабатывание на **70%**, Osu AutoDeafen будет отслеживать текущую игру в osu!

Когда ты достигнешь 70% карты, программа автоматически нажмёт заданную клавишу

Эту клавишу можно привязать к Discord Deafen, чтобы Discord автоматически заглушался перед сложной частью карты

## Требования

- Windows x64
- osu!
- Настроенный хоткей дефа/мута, если программа используется вместе с Discord

## Использование

1. Запусти `OsuAutoDeafen.exe`
2. Выбери процент срабатывания
3. Укажи клавишу, которую программа должна нажать
4. Начни играть в osu!
5. Дальше Osu AutoDeafen всё сделает автоматически

## Примечание

Osu AutoDeafen работает отдельно от osu! и не изменяет карты или игровой процесс

Программа только нажимает заданную клавишу при достижении выбранного процента
